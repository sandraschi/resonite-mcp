## 💻 Desktop Access

### **Steam Desktop App (Windows/macOS/Linux)**
**What you already know!** This is the primary desktop version.

#### **Installation:**
```
1. Install Steam client
2. Search for "Resonite"
3. Purchase/download (free demo available)
4. Launch from Steam library
```

#### **Requirements:**
- **OS:** Windows 10+, macOS 10.15+, Linux (SteamOS/Steam Deck)
- **CPU:** Quad-core 3.0 GHz minimum, 6-core recommended
- **RAM:** 8GB minimum, 16GB+ recommended
- **GPU:** GTX 1060 or equivalent minimum, RTX 2060+ recommended
- **Storage:** 2GB free space
- **Network:** Stable internet connection

#### **Features:**
- **Full ProtoFlux access** - Create and edit worlds
- **Advanced avatar customization** - Full VRM support
- **World building tools** - Complete creator toolkit
- **Multi-monitor support** - Use multiple displays
- **Keyboard/mouse control** - Traditional input methods

## 🎯 Meta Quest Access

### **Three Ways to Access Resonite on Quest:**

#### **Method 1: Quest Standalone App (Recommended)**
**Pure standalone VR experience - no PC required!**

##### **Installation:**
```
1. Put Quest into developer mode (sidequest required initially)
2. Install SideQuest on PC
3. Connect Quest via USB
4. Download Resonite APK from SideQuest
5. Install and launch
```

##### **Requirements:**
- **Quest 2/3/Pro** with latest software
- **SideQuest** for initial installation
- **Stable WiFi** for world access
- **Optional:** Meta account for cloud features

##### **Features:**
- **Full VR experience** - 6DOF tracking, hand tracking
- **World access** - Most public worlds
- **Avatar system** - Quest-optimized avatars
- **ProtoFlux viewing** - Can view and interact with ProtoFlux (limited editing)
- **Performance optimized** - Runs smoothly on Quest hardware

#### **Method 2: Quest Link (PC VR)**
**Use Quest as PC VR headset via cable/wireless**

##### **Setup:**
```
1. Install Oculus/Meta app on PC
2. Enable Quest Link in app settings
3. Connect via USB cable or WiFi
4. Install Resonite on PC via Steam
5. Launch Resonite in VR mode
```

##### **Advantages:**
- **Full PC features** - ProtoFlux editing, world building
- **Better performance** - PC hardware acceleration
- **Higher resolution** - PC rendering quality
- **Full creator tools** - No limitations

#### **Method 3: Air Link (Wireless PC VR)**
**Wireless streaming from PC to Quest**

##### **Setup:**
```
1. Enable Air Link in Quest settings
2. Install Oculus PC app
3. Enable Air Link on PC
4. Connect on same network
5. Launch Resonite on PC
```

##### **Best For:**
- **Cable-free VR** - No wires to trip over
- **Room-scale** - Full movement tracking
- **High performance** - PC-quality rendering

## 📱 Pico 4 Access

### **Primary Method: Pico Store**
**Official Pico ecosystem access**

#### **Installation:**
```
1. Turn on Pico 4
2. Open Pico Store app
3. Search for "Resonite"
4. Download and install
5. Launch from library
```

#### **Requirements:**
- **Pico 4 or 4 Pro** with latest firmware
- **Pico account** (free)
- **WiFi connection** for world access
- **Eye/Face tracking** optional but recommended

#### **Features:**
- **Full VR experience** - Inside-out tracking
- **Hand tracking** - Natural interaction
- **Eye tracking** - Enhanced avatars
- **6DOF controllers** - Precise input
- **Wireless** - No PC required

### **Alternative: SteamVR Mode**
**Use Pico 4 as PC VR headset**

#### **Setup:**
```
1. Install SteamVR on PC
2. Connect Pico 4 via WiFi/USB
3. Install Resonite via Steam on PC
4. Launch SteamVR, then Resonite
5. Select VR mode in Resonite
```

#### **Advantages:**
- **Full PC features** - World building, ProtoFlux editing
- **Higher fidelity** - PC rendering quality
- **Advanced tools** - Complete creator suite

## 🔧 Troubleshooting

### **Common Platform Issues:**

#### **Quest Standalone:**
- **Can't install:** Check developer mode setup
- **Poor performance:** Close background apps, restart device
- **Connection issues:** Check WiFi stability, restart router
- **Black screen:** Force restart Quest, reinstall app

#### **Pico 4:**
- **Tracking issues:** Recalibrate, clean cameras, good lighting
- **App crashes:** Clear cache, reinstall, check storage space
- **Audio problems:** Check Bluetooth settings, restart headset
- **Store access:** Verify Pico account, check region restrictions

#### **PC VR:**
- **SteamVR errors:** Restart SteamVR, update drivers
- **Controller issues:** Recalibrate, check batteries, update firmware
- **Performance drops:** Monitor GPU/CPU usage, adjust settings
- **Connection problems:** Check USB cables, try different ports

#### **Mobile:**
- **App instability:** Clear cache, update OS, reinstall app
- **Limited features:** Expected - mobile is view-only
- **Connection issues:** Check mobile data/WiFi, app permissions

### **Getting Help:**
- **Resonite Discord** - #help channels for each platform
- **Official forums** - Platform-specific troubleshooting
- **Community guides** - User-created setup tutorials
- **Developer logs** - Check Resonite logs for error details
