# 🎒 Resonite Community Resources & Ecosystem Guide

A comprehensive list of essential community tools, asset depots, development frameworks, and resource directories within the Resonite ecosystem.

---

## 🔧 Client Modifications & Extensions

### 1. **Resonite Mod Loader (RML)**
* **What it is**: The standard community modding framework for the Resonite PC client.
* **Purpose**: Allows developers to write C# DLL mods to add custom client-side behaviors, optimize performance, or tweak desktop controls.
* **Ecosystem Role**: Used by power users to load overlay UI utilities, custom hotkeys, or integration bridges for external hardware.

### 2. **ResoniteModLoader Discord**
* **What it is**: The developer Discord channel where mods are shared, updated, and reviewed for safety.

## 📦 In-World Asset Depots & Directories

Unlike other VR platforms, Resonite assets are saved and shared *directly in-world* through folders. Here are the major public folders you should bookmark:

### 1. **Resonite Essentials (Built-in)**
* **How to access**: Dash → Inventory → Resonite Essentials.
* **Content**: Contains default avatars, building blocks, ProtoFlux templates, interactive gadgets, and official tutorial guides.

### 2. **Community Created Depots**
* **How to access**: Search for "Depot" or "Library" in the **Worlds** tab.
* **Content**: Community-hosted spaces displaying public folders of:
  - Custom visual scripting prefabs (ProtoFlux helper chips).
  - Avatar bases (Quest-optimized, VRM compliant).
  - Textures, materials, and shaders.
  - Interactive systems (clocks, media players, locomotion engines).

## 🛠️ Developer Frameworks & Tools

### 1. **ResoniteLink**
* **What it is**: A WebSocket-based bridge running as an in-game mod/script that connects Resonite's internal scene hierarchy to external environments.
* **Fleet Integration**: Essential for the MCP server's real-time object spawning and spatial mapping tools.

### 2. **Blender-to-Resonite Exporters**
* **What it is**: Community Blender plugins to prepare 3D assets for drag-and-drop into Resonite (proper scaling, material setup, and skeleton alignment).

### 3. **OSC Controllers**
* **What it is**: Standalone utilities (like mobile apps or Python scripts) designed to send `/avatar/parameters/*` OSC signals to control avatar face tracking or world elements.
