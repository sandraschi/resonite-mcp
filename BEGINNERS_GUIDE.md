# 🎭 Resonite Beginner's Guide

**Welcome to Resonite!** This guide is for total beginners who have never used VR social platforms before. We'll start from the very basics and get you comfortable in this amazing virtual world.

---

## 🚀 What is Resonite?

**Resonite** is a social VR platform where you can:

- **Meet people** from around the world in virtual spaces
- **Create and share** your own worlds and objects
- **Experience VR** with or without a headset (desktop mode available)
- **Learn and build** using visual programming (ProtoFlux)
- **Make friends** and join communities

Think of it like a 3D version of the internet where you can walk around, meet people, and create things together!

---

## 📦 Getting Started (5 Minutes)

### Step 1: Install Resonite
1. Go to [Steam](https://store.steampowered.com/app/2519830/Resonite/)
2. Click "Install" and wait for download
3. Launch Resonite from Steam

### Step 2: First Time Setup
1. **Create Account:** Sign up with email or use existing account
2. **Choose Username:** Pick something fun and unique
3. **Graphics Settings:** Start with "Balanced" quality
4. **Audio Setup:** Test microphone if you want to talk

### Step 3: Enter Your First World
- You'll start in the **"Nexus"** - Resonite's main hub
- Look around with your mouse
- Walk with WASD keys

## 🎮 Basic Controls (Essential!)

### Movement (Like a Video Game)
```
W A S D     = Walk forward/left/back/right
Mouse       = Look around (hold right-click to look)
Space       = Jump
Shift       = Run faster
Ctrl        = Crouch down
```

### Essential Interface
```
Tab         = OPEN BOTTOM MENU (most important key!)
Esc         = Close menus, cancel things
E           = Interact with objects/people
F           = Focus on someone (like following them)
T           = Open text chat
Q           = Quick favorites menu
```

### Function Keys (Special Features)
```
F1          = Hide/show all menus (for screenshots)
F8          = Take screenshot
F9          = Mute/unmute microphone
F11         = Show performance stats
F12         = Emergency exit (if something goes wrong)
```

---

## 📋 The Bottom Menu (Your Best Friend)

**Press Tab** to open the bottom menu - this is where you do almost everything!

### Main Sections:
- **🏠 Worlds** - Browse and visit different places
- **👥 People** - Find friends and contacts
- **🎒 Inventory** - Your items and creations
- **⚙️ Settings** - Audio, graphics, controls
- **❓ Help** - Tutorials and guides
- **🔨 Create** - Building tools (advanced)

### How to Use the Menu:
1. **Press Tab** to open
2. **Click** on sections with mouse
3. **Hold Tab** to keep menu open while browsing
4. **Esc** or click outside to close

## 🌍 Your First World: The Tutorial

### How to Get There:
1. Press **Tab** to open bottom menu
2. Click **"Worlds"** section
3. Look for **"Tutorial"** or **"TutorialWorld"**
4. Click it and select **"Visit"**

### What You'll Learn:
The tutorial teaches you:
- ✅ How to walk and look around
- ✅ How to grab and move objects
- ✅ How to use basic tools
- ✅ How to talk to people
- ✅ Basic social features

**Don't skip the tutorial!** It's quick and teaches everything you need to know.

## 💬 Talking to People

### Text Chat:
1. Press **T** to open chat
2. Type your message
3. Press Enter to send
4. Press T again to close

### Voice Chat:
1. Make sure your microphone works (test in settings)
2. Press **F9** to mute/unmute
3. Talk normally - people nearby will hear you
4. Use **F10** for push-to-talk if preferred

### Finding People:
1. Press **Tab** → **People**
2. Search for friends by name
3. Click their name to visit them
4. Or look for the **"Social Hub"** world to meet new people

## 🎯 Basic Interaction

### Objects and People:
```
E           = Grab/interact (point at object, press E)
Right-click = Context menu (options for that object)
F           = Focus/follow someone
Middle-click= Quick focus on distant things
```

### Moving Objects:
1. Point at object with crosshair
2. Press **E** to grab
3. Move mouse to move object
4. Press **E** again to drop
5. Press **R** while holding to rotate

- **Custom gestures** - press **G** for gesture menu

## 🔧 Troubleshooting Common Issues

### "I can't move!"
- Make sure you're not in a menu (press Esc)
- Check if you're stuck in an object
- Try jumping (Space) or crouching (Ctrl)

### "People can't hear me!"
- Press **F9** to unmute microphone
- Check microphone settings in **Tab → Settings → Audio**
- Make sure Windows hasn't muted you

### "Everything is laggy!"
- Press **F11** to see performance stats
- Lower graphics quality in **Tab → Settings → Graphics**
- Close other programs using CPU

### "I got lost!"
- Press **Tab → Worlds → Home** to go back to a safe place
- Look for portals or doors that say "Exit"
- Ask in chat for help
